# Junto Nova Website

Official website for **Junto Nova** — strategy consulting focused on driving down the costs of living for American families.

## Structure

- Single-page site with three main sections:
  - **Dashboard** — cost-of-living projections + interactive “What if?” calculator
  - **Services** — rate card and engagement models
  - **Vision** — purpose and operating principles

## Stack

- Tailwind CSS (CDN)
- Chart.js
- Pure HTML/CSS/JS (no build step)

## Local preview

Just open `index.html` in a browser.

## Deployment

Designed for static hosting (GitHub Pages, Porkbun Static, Netlify, etc).
